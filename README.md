# 🚀 ArogyaAI – AI-Powered Health & Nutrition Platform

ArogyaAI is a comprehensive AI-driven health ecosystem that combines **computer vision, IoT, and intelligent automation** to deliver personalized nutrition, fitness, and real-time health insights.

It transforms traditional health tracking into a **proactive, data-driven decision-making system**.

---

## 🌟 Overview

Modern health applications are often fragmented and require manual input. ArogyaAI solves this by creating a **fully automated, intelligent, and integrated platform** that connects:

- 📷 Food Intelligence  
- 🧠 AI-driven insights  
- 🏋️ Fitness tracking  
- 🧬 Genetic + demographic personalization  
- ⌚ Real-time biometric monitoring (IoT)  

👉 **From tracking → to intelligent health guidance**

##🏗️ Project Architecture

```bash
ArogyaAI/
│
├── backend/        # Node.js + Express + PostgreSQL

├── esp32/          # IoT Sensor Firmware
├── n8n-workflows/  # Automation pipelines
```

---

## ⚙️ Tech Stack

### 💻 Frontend (Mobile)
- React Native (Expo)  
- React Navigation  
- React Query  

---

### 🖥️ Backend
- Node.js + Express  
- PostgreSQL  
- OpenAI APIs (GPT-4o, Whisper, TTS)  

---

### 🔌 IoT & Hardware
- ESP32 Microcontroller  
- MAX30102 (Heart Rate + SpO2)  
- AD8232 (ECG Sensor)  
- DS18B20 (Temperature)  

---

### 🔄 Automation
- n8n workflows  
- SMTP, Twilio, Slack integrations

# 🚀 How It Works

1. 📷 User scans food → AI detects nutrients  

2. 🧠 AI analyzes:
   - Calories & macros  
   - User profile  
   - Genetic & sensor data  

3. 📊 System outputs:
   - Diet improvements  
   - Exercise recommendations  

4. ⌚ Sensors provide real-time feedback  

5. 🔄 System continuously adapts  

👉 **Closed-loop intelligent health system**

## ⚡ Quick Start

### 1️⃣ Backend Setup

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

---

### 2️⃣ Mobile App

```bash
cd mobile
npm install
npx expo start
```

---

### 3️⃣ ESP32 Setup

- Upload firmware via Arduino IDE  
- Connect sensors  
- Configure WiFi  

---

### 4️⃣ Automation (n8n)

```bash
npm install -g n8n
npx n8n
```
